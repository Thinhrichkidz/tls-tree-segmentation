Steps processing pipeline

    Step 1.Preprocessing in RiSCAN PRO (Q-ForestLab) to a plot point cloud (filter, crop,
         downsample)

    Step 2.Run RayCloudTools (RCT) to segment the plot into individual trees
    Step 3.Run script to extract those individual trees from the plot point cloud so you get a

         "leftover" point cloud
    Step 4.Correct the individual tree segmentation in CloudCompare

This course practical actually goes through step 2 & 4:
https://github.com/qforestlab/ARS_TLS_course

Step 2. Run RCT:

Manual to run RCT: https://github.com/qforestlab/rayextract-manual
Notebook on these first steps:
https://github.com/qforestlab/ARS_TLS_course/blob/main/notebooks/01_ARS_TLS_practical
_RCT.ipynb
